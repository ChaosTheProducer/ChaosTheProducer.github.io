# Paper Preview Images

Put paper architecture figures or representative preview images in this folder.

Recommended format:

- Use `.png`, `.jpg`, or `.webp`.
- Prefer landscape images around `1200x700` or `1200x800`.
- Keep filenames stable and simple, for example:
  - `dts.png`
  - `prefbench.png`
  - `ttt4d.png`

Then reference the image in `content/publications.bib`:

```bibtex
preview = {prefbench.png},
```

Only write the filename in BibTeX. The website loads it from `/paper-previews/`.
